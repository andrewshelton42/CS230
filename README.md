The Gaming Room client desired a web-based application for their game, Draw It or Lose It. The game needed to support multiple players, multiple rooms, and gradually
reveal an image to the players while they attempted to recreate it. As a result, the software needed to have low latency and storage requirements.

I believe I did well recognizing the limitations of each possible platform for the application and identifying the client's requirements. Laying out the requirements
and the different aspects of each platform made the process of recommending one for the client at the end much simpler.
